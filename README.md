## The entry

> My smart fridge has Wi-Fi, a touchscreen, and a camera inside — and after six years of firmware updates it still can't make one cube of ice.

The angle: a fridge stuffed with tech (Wi-Fi, touchscreen, camera, weekly
firmware updates) that still cannot do the one job a fridge exists for —
make ice. It dodges the obvious cracks (milk expired, "update required to
open the door", the fridge watching you) and lands its turn at the end.

## Run it

```sh
python3 main.py
```

Writes the single line to `/output/entry.txt`. Pure Python standard
library, deterministic — the same bytes on every run.
